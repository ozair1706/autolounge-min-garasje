## Short description (copy into Canvas)

**AutoLounge Min Garasje** is a web application prototype developed with AI-assisted coding (Vibe Coding). It is inspired by a real challenge at AutoLounge AS, a Norwegian tyre and wheel service company: employees often have to call tyre hotel customers manually when their tyres may need replacement.

The app has three working features. Employees can import fictional Eontyre-style tyre hotel data from Excel, JSON, or CSV, create three personalized tyre offers, and demonstrate how customers can select an offer or request a callback. The workshop dashboard displays the customer's simulated response. The prototype is built with HTML, CSS, and JavaScript and works in a browser.

I used ChatGPT to brainstorm the idea, plan the features, generate and refine code, and test the application. During testing, I fixed a winter-tyre status bug, improved the file import formats, and refined the mobile design and AutoLounge branding. I used only fictional customer data. Real SMS, payments, customer login, and direct Eontyre integration are outside the scope of this prototype.
