# Slik leverer du AutoLounge Min Garasje via GitHub

1. Åpne https://github.com/new og logg inn.
2. Kall repositoriet `autolounge-min-garasje`, velg **Public**, og opprett et tomt repository (ikke opprett ny README).
3. Åpne dette repositoryet og velg **Add file → Upload files**.
4. Pakk ut ZIP-filen på PC-en og åpne den utpakkede mappen. Dra **alle filene og mappene inni** (ikke en ny toppmappe og ikke selve ZIP-filen) til GitHub.
5. Kontroller at `README.md`, `index.html`, `styles.css` og `app.js` ligger direkte i toppnivået. `assets/`, `testdata/` og `skjermbilder/` skal også vises.
6. Skriv f.eks. `Initial commit – AutoLounge Min Garasje` og velg **Commit changes**.
7. Kopier repositorieadressen: `https://github.com/DITTBRUKERNAVN/autolounge-min-garasje` og legg inn i Canvas.
8. Legg inn videolenken https://youtu.be/AUY8g1Wwctg og kortbeskrivelsen fra `INNLEVERING.md`.

Ikke last opp ekte kundedata, API-nøkler eller Eontyre-eksporter. Kun fiktive testfiler.
